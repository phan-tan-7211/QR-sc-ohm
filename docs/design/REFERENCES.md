# UI/UX References

Các repo dưới đây chỉ là nguồn tham khảo, không được copy source hoặc cài toàn bộ vào project.

- [Industrial Machine UI Simulator](https://github.com/ThangNT9x/industrial-machine-ui-simulator) — tham khảo workflow công nghiệp, machine state, alarm và recipe/config.
- [ModernWPF](https://github.com/Kinnara/ModernWpf) — tham khảo visual language WPF, controls, typography, navigation và spacing.
- [HandyControl](https://github.com/HandyOrg/HandyControl) — tham khảo control patterns, đặc biệt engineering settings.

Khi reference repo thay đổi, QR-SC-OHM vẫn tuân theo các quyết định đã chắt lọc trong `DESIGN_SYSTEM.md`, `UX_SPEC.md` và `LAYOUT_SPEC.md`. Không lấy màu, layout hoặc dependency mới từ reference nếu chưa cập nhật spec và được duyệt.
